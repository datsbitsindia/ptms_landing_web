Frequently Asked Questions

How does PTMS UNO handle multi-tenant organization security?
Every organization created in PTMS UNO is bound to a unique organization ID and strict database query scoping. Users can only access projects, tasks, and routines linked to their organization.
Can I download native desktop (.EXE) and mobile (.APK) apps?
Yes! PTMS UNO provides native Windows Desktop (.EXE) installers and Android Mobile (.APK) packages. Simply click the download buttons in the Download section above.
What happens if I try to assign a project without selecting a manager?
PTMS UNO includes strict validation. If a user attempts to submit a project form without assigning a manager, the system immediately blocks submission and displays a clear alert modal requesting manager selection.

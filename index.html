Frequently Asked Questions

How does PTMS UNO handle multi-tenant organization security?
Every organization is bound to a unique organization_id. All database queries are scoped to that ID ” users can only see their own org's projects, tasks, employees, and routines. Switching organizations via the org-switcher API is also fully guarded with session validation.
Can I download native Windows (.EXE) and Android (.APK) apps?
Yes! PTMS UNO offers a native Windows Desktop (.EXE) installer and an Android (.APK) package. Both connect to the same cloud database. Download links are available in the Downloads section. The web app also supports PWA install ” tap "Add to Home Screen" in Chrome.
What are the three user roles and what can each do?
Admin ” Full access: creates users, projects, all tasks, views audit logs and reports.
Manager ” Manages assigned projects, creates & forwards tasks, views team performance reports, manages daily routines.
Employee ” Views and updates assigned tasks, forwards tasks, adds comments and file attachments, completes daily routines.
How does Task Forwarding work?
Any user can forward a task to another employee or manager with a reason. Every forward is logged in task_forward_logs ” creating a complete chain of custody. This means you always know who handled a task, when, and why it was forwarded. Managers can reassign tasks between employees as well.
What is Daily Routine Automation and how does it work?
Managers can create recurring routines linked to projects. The system auto-generates a new daily log entry every day (or on configured weekdays) for each assigned employee. Employees mark their daily routine as complete, and managers can track completion rate across all employees ” no manual task creation needed.
How does the AI Assistant create and manage tasks?
The AI uses Google Gemini + Groq + OpenRouter models in cascade. It connects to a Python FastMCP server that directly queries your cloud database. You can say "Create a High priority task for Alex ” API bug fix, due Friday" and the AI validates your active projects and team members from the DB, then creates the task ” no hallucination possible.
Can I attach files and add comments to tasks?
Yes. Every task supports file attachments (PDF, images, Word docs) via Multer upload middleware. Files are stored securely and downloadable from the task detail page. Any user assigned to the task can also post comments with timestamps, creating a full conversation thread per task.
What reports and analytics does PTMS UNO provide?
Managers get a live Reports dashboard with: task breakdown by status, per-employee completion rates, project-wise task counts, overdue task alerts, and tasks due in the next 3 days. All data is filtered to the manager's own organization and projects ” no data leakage across tenants.
How does Live Sync work across devices?
PTMS UNO runs a background /api/live-check polling interval. When a new task is assigned, a routine is updated, or a notification is sent, the UI silently refreshes the relevant section ” no full page reload needed. This keeps the dashboard always current, whether you're on web, Windows, or Android.
How secure is the authentication system?
PTMS UNO uses express-session with a strong secret and bcrypt (12 rounds) for password hashing. Every route is protected by role-based middleware (requireAuth, requireAdmin, requireManager). All critical actions are logged to an audit_events table via database triggers for a complete tamper-proof trail.
Can employees and managers use voice commands in the AI?
Yes! The built-in AI chat supports voice input via Groq Whisper Large v3 Turbo ” the world's fastest speech-to-text. Speak in Hindi, English, or Hinglish. The AI auto-corrects team member names and project names from your live database. Responses are also read aloud in Indian accent English (en-IN) for hands-free use.
Does the database auto-setup on first run?
Yes. On first start, PTMS UNO's database/init.js automatically creates all tables, indexes, database views, triggers, and seed data. No manual SQL import needed. Just configure your .env file with database credentials and run npm start ” the system handles the rest.
